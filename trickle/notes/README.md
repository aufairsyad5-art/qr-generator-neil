# QR Gratis - Project Overview

A high-quality, professional-grade QR Code Generator application built with React, TailwindCSS, and Lucide Icons.

## Features
- **Real-time Generation**: Instant QR code updates as you type content or modify any visual settings.
- **Customization**: Change background and foreground colors.
- **Logo Integration**: Upload custom branding logos to the center of the QR code.
- **Custom Labels**: Add and edit text labels at the top, bottom, left, and right of the QR code, beautifully integrated with the QR frame.
- **Multiple Formats**: Export as PNG or JPEG.
- **Structured QR Types**: Email and WiFi tabs generate `mailto:` and `WIFI:` payloads.
- **History Tracking**: Saves the last 10 generated QR codes locally.
- **Branding**: Displays Neil Irsyad below the Advanced QR Engine label.
- **Mobile Optimized**: Responsive design for all devices.

## Tech Stack
- React 18
- Tailwind CSS (Theme-based design system)
- QRCode.js (Engine)
- Lucide Icons (Static font)

## Maintenance Rules
- Whenever the project is updated (new features, bug fixes), this `README.md` must be reviewed and updated if necessary.
- Ensure all new components follow the `data-name` and `data-file` attributes convention.
- Icons must follow the Lucide shape-first naming convention (e.g., `circle-play`).
