When updating the project:
- Always check if the `trickle/notes/README.md` needs an update to reflect new features or architectural changes.
- Ensure all icons use the `icon-{name}` format with static CSS classes.
- Maintain the modular structure (components in `components/`, entry in `app.js`).
- Prioritize high contrast for visibility, especially for icons on colored backgrounds.
- Always check for the existence of external libraries (like `window.QRCode`) before calling their methods.
